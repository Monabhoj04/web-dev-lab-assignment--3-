
# Web Dev I Lab Assignment 3
## Responsive Personal Portfolio Website

### Student Details
Name: Monaa Bhoj  
Course: B.Tech CSE (Artificial Intelligence and Machine Learning)

### Project Description
This project is a personal portfolio website developed using HTML5 and CSS3.

The website includes:
- Header and Navigation Bar
- Hero Section
- About Me Section
- Skills Section
- Projects Section
- Contact Form
- Footer

### Technologies Used
- HTML5
- CSS3
- Google Fonts
- Visual Studio Code
- Live Server

### CSS Concepts Implemented
- Flexbox for layout and alignment
- CSS Grid for Skills and Projects sections
- Media Queries for responsive design
- Relative units such as rem, %, vw and vh
- Hover effects and CSS transitions
- Keyframe animations
- CSS transforms

### How to Run the Project
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open index.html using Live Server.
4. The portfolio website will open in your browser.

### Responsive Testing
The website includes the following CSS breakpoints:

- Desktop: Above 900px
- Tablet: 600px to 900px
- Mobile: 600px and below

Tested using Chrome browser at desktop, tablet and mobile viewport sizes.
